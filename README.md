# Sentence Lab — מעבדת משפטים

אפליקציה אישית לתרגול בניית משפטים באנגלית — בנגיעות, בלי להקליד. היא מחזקת בדיוק את ההחלטות שעוצרות את הדיבור:
פועל העזר, צורת הפועל שאחריו, סדר המילים בשאלה, ובחירת המבנה שמתאים למשמעות.

## שימוש יומיומי

- **פותחים ולוחצים "המשך".** האפליקציה בוחרת מה לתרגל ומתי לחזור. היקף: קצר (6), רגיל (14) או מעמיק (24) משימות.
- **התקנה בטלפון** (אחרי שהאתר מתארח בכתובת HTTPS):
  - Android / Chrome: תפריט ⋮ ← "התקנת אפליקציה" או "הוספה למסך הבית".
  - iPhone / Safari: כפתור השיתוף ← "הוספה למסך הבית".
- **בלי רשת:** אחרי טעינה מלאה אחת עם חיבור, מופיע "זמין ללא רשת במכשיר הזה", והאפליקציה עובדת גם בלי חיבור.
- **גיבוי:** הגדרות ← "ייצא גיבוי" (קובץ JSON). שחזור: הגדרות ← "שחזר מגיבוי". ההתקדמות נשמרת רק בדפדפן במכשיר —
  זה לא גיבוי בענן ואין סנכרון בין מכשירים. כדאי לגבות מדי פעם, למשל ל-Drive.
- **כרטיס לתרגול קולי:** "ההתקדמות שלי" ← "הכן כרטיס לתרגול קולי". הכרטיס נבנה מהתשובות שלך (מה חלש, משפטים
  בעברית עם התשובות, וכללים שמונעים מהמורה הקולי לסיים מוקדם או להחליף נושא). מעתיקים ומדביקים בשיחה עם ChatGPT
  או Gemini **לפני** הנסיעה. האפליקציה לא שולחת אותו לשום מקום.
- **יש בעיה בשאלה?** בכל תרגיל: "עוד" ← "יש בעיה בשאלה". הניסיון לא נספר עד שהשאלה נבדקת, והדיווחים ניתנים לייצוא
  מההגדרות.

## איך זה עובד — בקצרה

- **חמישה סוגי תרגילים:** הרכבת משפט, תיקון ממוקד (כולל משפטים שכבר תקינים), שינוי משפט, הבחנת משמעות, ודיאלוג קצר.
- **השמעה קולית טבעית (TTS):** כפתור שמע לצד משפטי הדוגמה, ההסברים והמשוב, עם אפשרות להאזנה במהירות רגילה (0.95x) או איטית (0.75x) בעזרת Web Speech API ללא תלות ברשת.
- **חוויית בנייה משופרת (Builder UX):** כפתור ביטול צעד (Undo) מחזיר את המילה האחרונה לבנק במקום להתחיל מחדש; תמיכה במקשי מקלדת (`Backspace` וספרות `1`–`9`); ומשוב רטט עדין (Haptics) במובייל.
- **בדיקה חכמה ומדויקת:** בדיקה מול חלופות, טעויות מוכרות וקיצורי דיבור (Spoken Contractions כמו `She's` במקום `She has`), ללא מודל שפה בזמן התרגול.
- **שיתוף וגיבוי נוח:** תמיכה ב-Web Share API לייצוא ושמירת קובץ הגיבוי ישירות ל-Google Drive, למנהל הקבצים או לאפליקציות במכשיר.
- **ראיות ולא ציון:** הצלחה מיד אחרי שראית את התשובה נרשמת כתיקון בעזרה. התקדמות נמדדת בניסיון ראשון, בלי רמז,
  בפריט חדש, בהקשרים ובסוגי תרגיל שונים.
- **חזרות מרווחות וחכמות:** מנגנון מרווחים (1, 3, 7, 14, 30 ימים) עם מנגנון צינון פריטים מוכרים (14 ימים) המונע תקיעות ביחידות קצרות ומאפשר התקדמות רציפה ב-Retention Ladder.
- **מה לא נמדד:** דיבור עצמאי, הגייה ושטף.

## למפתחים

דרישות: Node.js 24.

```bash
npm install            # התקנת תלויות (גרסאות נעולות ב-package-lock.json)
npm run dev            # שרת פיתוח
npm test               # בדיקות יחידה (מנוע, בדיקת תשובות, מרווחים, אחסון, גיבוי)
npm run validate:content   # בדיקת תקינות מאגר התרגילים
npx playwright install chromium webkit   # פעם אחת, לבדיקות קצה-לקצה
npm run test:e2e       # בדיקות קצה-לקצה ב-Chromium וב-WebKit, ברוחב 360 ו-390
npm run build          # בנייה לייצור → dist/ (PWA עם service worker)
npm run build:single   # קובץ HTML יחיד → artifact/sentence-lab.html (לתצוגה ב-Claude, בלי עבודה ללא רשת)
npm run icons          # יצירת האייקונים מחדש
```

### מבנה

```
src/content/     מאגר התרגילים (schema.ts, skills/s01…s12.ts, calibration.ts, units.ts, validate.ts)
src/engine/      המנוע — פונקציות טהורות, בלי UI:
                 evaluate (בדיקת תשובות) · builder (בניית משפט בנגיעות) · schedule (מרווחים וזכאות לבדיקה)
                 select (בחירת התרגיל הבא + reasonCode) · session (מכונת המצבים של מקטע) · progress (ראיות)
src/storage/     IndexedDB (טרנזקציה אחת לכל צעד, הגנה מפני שתי לשוניות), גיבוי ושחזור עם אימות
src/screens/     המסכים (היום, המסלול שלי, ההתקדמות שלי, תרגול, הגדרות)
tests/unit/      Vitest   ·   tests/e2e/   Playwright
docs/CONTENT_GUIDE.md   הנחיות לכתיבת תרגילים
```

המנוע לא יודע דבר על React או על המסך: כל צעד מקבל מצב ומחזיר את השינוי לשמירה. לכן אפשר בעתיד לחבר אליו ממשק
אחר — למשל ממשק קולי שבו זיהוי דיבור מחליף את הנגיעות — בלי לשנות את התוכן, הבדיקה או המרווחים.

## פריסה — רק למי שאתה מאשר

`dist/` הוא אתר סטטי: אין שרת, אין מפתחות ואין שירותי צד שלישי. הנתיבים יחסיים (`base: './'`).
ההתקדמות של כל משתמש נשמרת רק במכשיר שלו — אף אחד לא רואה נתונים של אחר.

**עכשיו — העותק הפרטי ב-Claude:** גרסת הקובץ היחיד (`artifact/sentence-lab.html`) מפורסמת כ-Artifact פרטי ב-claude.ai.
בהתחלה רק אתה רואה אותו; אפשר לשתף עם מי שתבחר מהגדרות השיתוף ב-claude.ai. עובד בטלפון מהדפדפן או מאפליקציית
Claude. בלי התקנה כאפליקציה ובלי עבודה ללא רשת; אפשר להוסיף קיצור למסך הבית מתפריט הדפדפן.

**בהמשך, אם תרצה התקנה ועבודה ללא רשת — Cloudflare Pages + Cloudflare Access (בחינם), עם רשימת מיילים מאושרים:**
1. נרשמים ל-Cloudflare ונכנסים ל-Workers & Pages ← Create ← Pages ← Upload assets. נותנים שם (למשל `sentence-lab`)
   ומעלים את התיקייה `dist` (או `app` בתיקיית ה-Drive).
2. ב-Zero Trust ← Access ← Applications ← Add an application ← Self-hosted. הדומיין: הכתובת שקיבלת ב-`pages.dev`.
3. מוסיפים מדיניות Allow עם Include ← Emails ← כתובת המייל שלך, ושל כל מי שאתה מאשר. שיטת הכניסה: One-time PIN
   (קוד שנשלח למייל). כדי לאשר אדם נוסף בהמשך — מוסיפים את המייל שלו לרשימה.
4. פותחים את הכתובת בטלפון, מזינים את הקוד מהמייל, ואז "הוספה למסך הבית".

מי שלא ברשימה לא יכול לפתוח את האתר.

> GitHub Pages לא מתאים לדרישה "רק מי שאני מאשר": באתרים של חשבון רגיל האתר ציבורי לכל מי שיש לו את הכתובת.
